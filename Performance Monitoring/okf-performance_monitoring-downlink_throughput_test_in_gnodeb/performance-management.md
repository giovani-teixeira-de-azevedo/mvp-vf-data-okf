Performance management for the Downlink Throughput Test in gNodeB feature serves two primary purposes: tracking the outcomes of the tests themselves (to verify if cells are meeting their expected downlink capability) and supervising the feature's own footprint (to monitor how much air-interface volume is spent on testing). 

All counters are collected per cell over the standard 15-minute Result Output Period (ROP), in addition to the per-test records. Test verdicts should be trended per cell across software upgrades and hardware interventions; a step change in verdict distribution after an upgrade serves as a rapid regression signal.

## Key Performance Indicators (KPIs)

A healthy cell population typically exhibits a **Test Pass Ratio** above 90%. 
* **Persistent FAILED verdicts** on a cell with good reported CQI point to node-side issues (such as VSWR, baseband capacity, or a misconfigured carrier).
* **FAILED verdicts correlated with poor CQI** indicate a coverage or interference problem, which should be investigated using NR UE Coverage Measurements.
* A **Test Abort Ratio** above ~5% usually indicates that tests are being run against mobile UEs without `followOnHandover` enabled (see [Parameters](parameters.md)).
* The **Test Load Share** quantifies the capacity cost of the test regime and should remain below 1% of cell volume for routine automated testing.

| KPI | Formula | Description |
| :--- | :--- | :--- |
| **Test Pass Ratio** | `ctrTestsPassed / ctrTestsCompleted × 100` | Share of completed tests with PASSED verdict (%) |
| **Test Fail Ratio** | `ctrTestsFailed / ctrTestsCompleted × 100` | Share of completed tests with FAILED verdict (%) |
| **Test Abort Ratio** | `ctrTestsAborted / (ctrTestsCompleted + ctrTestsAborted) × 100` | Share of started tests aborted before completion (%) |
| **Test Load Share** | `ctrTestDataVolume / ctrCellDlDataVolume × 100` | Share of cell DL volume generated by tests (%) |

## Counters

The performance counters separate test outcomes from test cost. 
* **`ctrTestsAborted`**: Aborts caused by UE release or handover are expected occasionally. However, aborts flagged with the cause `RESOURCE_DENIED` indicate that the scheduler could not grant even the capped share, signaling that the cell is congested enough that testing should be rescheduled to off-peak hours.
* **`ctrTestDataVolume`**: Allows test traffic to be subtracted from capacity trending to maintain accurate baseline measurements.

| Counter | Description | Range | Datatype |
| :--- | :--- | :--- | :--- |
| `ctrTestsCompleted` | Tests run to full duration | 0–2³¹ | `int64` |
| `ctrTestsPassed` | Completed tests with PASSED verdict | 0–2³¹ | `int64` |
| `ctrTestsDegraded` | Completed tests with DEGRADED verdict | 0–2³¹ | `int64` |
| `ctrTestsFailed` | Completed tests with FAILED verdict | 0–2³¹ | `int64` |
| `ctrTestsAborted` | Tests aborted (UE release, handover, resource denial) | 0–2³¹ | `int64` |
| `ctrTestDataVolume` | PDCP volume generated by tests (kB) per ROP | 0–2⁶³ | `int64` |
| `ctrCellDlDataVolume` | Total cell DL PDCP volume (kB) per ROP | 0–2⁶³ | `int64` |
